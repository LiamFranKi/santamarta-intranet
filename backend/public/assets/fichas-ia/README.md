# Assets del Diseñador de fichas

Coloque aquí imágenes PNG (fondo transparente recomendado):

| Archivo | Uso |
|---------|-----|
| `logo-vanguard.png` | Encabezado derecho |
| `avatar-nino.png`, `avatar-nino1.png` … | Mascotas niño (prefijo `avatar-nino`) |
| `avatar-nina1.png` … `avatar-nina6.png` | Mascotas niña (prefijo `avatar-nina`) |
| `mascota-*.png` | Otras ilustraciones con prefijo `mascota-` |

Todos los `avatar-*.png` de esta carpeta se muestran en la ficha (orden alfabético). Use nombres con prefijo `avatar-` o `mascota-` y extensión `.png`.
| `icono-recuerda.png` | Opcional caja Recuerda |

Si falta el logo, la plantilla muestra el texto "VANGUARD Schools".

URL en producción: `https://sistema.vanguardschools.edu.pe/assets/fichas-ia/nombre.png`
