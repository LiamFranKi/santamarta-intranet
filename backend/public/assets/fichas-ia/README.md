# Assets del Diseñador de fichas

Coloque aquí imágenes PNG (fondo transparente recomendado):

| Archivo | Uso |
|---------|-----|
| `logo-vanguard.png` | Encabezado derecho |
| `avatar-nino.png` | Mascota (siempre en la ficha, junto a la intro) |
| `avatar-nina.png` | Mascota (siempre en la ficha) |
| `mascota-*.png` | Más ilustraciones: nombre con prefijo `mascota-` o `avatar-` |
| `icono-recuerda.png` | Opcional caja Recuerda |

Si falta el logo, la plantilla muestra el texto "VANGUARD Schools".

URL en producción: `https://sistema.vanguardschools.edu.pe/assets/fichas-ia/nombre.png`
